# CodeAlpha Internship - Task 3
## Email Address Extractor

This Python script reads email addresses from `input_emails.txt`, extracts unique addresses using Python's `re` module, and saves them to `extracted_emails.txt`.

### Files
- `email_extractor.py` — Python program
- `input_emails.txt` — sample input text
- `extracted_emails.txt` — sample output

### How to run
Keep `email_extractor.py` and `input_emails.txt` in the same folder, then run:
`python email_extractor.py`

Sample email addresses are included for demonstration.
