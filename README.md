## Task 1: Python Hangman Game

This is a simple Hangman game developed using Python.

### Features
- Five predefined words
- Six incorrect guesses allowed
- Accepts one letter at a time
- Checks repeated guesses
- Displays win or game over messages

## Task 2: Stock Portfolio Tracker

A Python program to calculate stock investment based on stock name and quantity.

### Features
- Displays available stocks and sample prices
- Calculates investment for each stock
- Calculates total investment
- Saves the portfolio report as a text file

### Technology Used
Python

### Files
- stock_portfolio_tracker.py
- stock_portfolio_report.txt

Note: Stock prices are sample values, not live market prices.
